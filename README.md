# Опасные корни

Локальный интерактивный тренажёр по корням-омофонам для подготовки к ЕГЭ.

## Запуск

Из папки проекта:

```powershell
python -m http.server 8765
```

Либо запустить двойным щелчком `start-preview.cmd`.

Затем открыть <http://127.0.0.1:8765/>.

Зависимости и сборка не нужны. Прогресс и журнал ошибок хранятся в `localStorage` браузера.

## Структура

- `index.html` — интерфейс;
- `styles.css` — адаптивное оформление;
- `script.js` — логика проверки, навигации и сохранения;
- `data/cards.js` — 115 уникальных учебных карточек и ответы;
- `assets/cards/` — нарезанные изображения;
- `tools/crop_cards.ps1` — воспроизводимая нарезка 19 исходных листов.
- `start-preview.cmd` — быстрый запуск локального предпросмотра.

## Проверка

```powershell
node tests/smoke.js
```

Тест проверяет целостность 115 записей, наличие изображений, правильный ответ,
раздельную блокировку частей, журнал ошибок и специальные режимы для словарных
слов и гласных, уже находящихся под ударением.
